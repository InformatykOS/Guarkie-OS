# Guarkie-OS
Guarkie OS is a Debian-based fork that comes with Snap, Flatpak, and Wine-HQ pre-installed, allowing you to run Windows programs—everything is right at your fingertips. It’s a beta version, so aside from the name, it’s still essentially Debian; you might even see "Cubic" and a timestamp in the system info—honestly, Cubic can be a real pain. Cheers! https://www.youtube.com/@iLinexy
